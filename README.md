## Description

A small website based on the provided Session 1 starter files. This repository
demonstrates meaningful commits, selective staging, branching, merging, and
synchronizing a local Git repository with GitHub.

## Technologies

- HTML5 for page structure
- CSS for styling
- JavaScript for the project status message
- Git and GitHub for version control

## Run locally

Open `index.html` in a browser, or serve this folder with Python:

```sh
python -m http.server 8000
```

Then open [the local project](http://localhost:8000).

## Ignore rules

`local.env` and ordinary `*.log` files are ignored. The `!important.log`
exception keeps the required log tracked. Temporary tooling files in `tmp/`
are also ignored.
